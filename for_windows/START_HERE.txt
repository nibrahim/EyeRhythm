EyesRhythm for Windows
======================

1. Unzip the whole folder. Keep EyesRhythm.exe and the _internal folder together.
2. Double-click EyesRhythm.exe. The app clears Windows “downloaded file”
   blocks on first launch so the desktop window can open.
3. If the window still opens in a browser instead:
   Double-click Unblock-and-run.bat in this folder, or right-click the zip
   → Properties → tick Unblock → Apply, then extract again.
4. Allow the camera when Windows asks.

If the window still does not open, send these two files back:

  %LOCALAPPDATA%\EyesRhythm\crash.log
  %LOCALAPPDATA%\EyesRhythm\runtime.log

(Paste that path into File Explorer’s address bar.)
